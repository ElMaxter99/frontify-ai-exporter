# Code of Conduct / Código de conducta

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) (© Contributor Covenant, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).

**Our standard / Nuestro estándar.** Be respectful, welcoming and constructive. Harassment, discrimination, personal attacks, trolling, or publishing others' private information are not acceptable. / Sé respetuoso y constructivo. No se tolera el acoso, la discriminación, los ataques personales ni la publicación de datos privados.

**Enforcement / Aplicación.** Maintainers may remove comments, issues or contributions that violate this code and may block repeat offenders. Report problems through a private GitHub security advisory or by contacting the maintainer, [@ElMaxter99](https://github.com/ElMaxter99). / Los mantenedores pueden eliminar contenido y bloquear a quien lo incumpla de forma reiterada.
